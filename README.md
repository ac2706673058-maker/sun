# 橙阅 ChengYue · iOS 小说阅读器

对标番茄小说、以「阅读界面细节做到极致」为目标的原生 iOS 阅读器。
纯 SwiftUI + UIKit 互操作，**未接入任何书源**，书库为内置样例内容（3 本完整撰写的样例小说 + 9 本书城陈列样例书）。

## 打开与运行

```bash
open ChengYue.xcodeproj      # 需要 Xcode 16 及以上（工程使用文件系统同步分组）
```

选择任意 iPhone 模拟器直接运行。最低支持 iOS 17.0。

工程文件是手写的；如果你的 Xcode 版本无法打开，仓库里附带了等价的 `project.yml`，执行 `xcodegen generate` 可以重新生成一份。

## 目录结构

```
ChengYue/
├─ App/           入口、Tab 容器、全局导航
├─ Core/          数据模型、本地存储、阅读配置、主题、触感
├─ Reading/       ★ 阅读内核：排版、真分页、页面渲染、翻页容器、听书/自动阅读
├─ Features/
│  ├─ Reader/     阅读界面：正文层、菜单层、六个设置面板、目录/书签/想法
│  ├─ Shelf/      书架、矢量封面
│  ├─ Store/      书城、书籍详情、搜索
│  └─ Profile/    阅读统计、偏好设置
├─ Content/       内置样例书正文
└─ Resources/     资源目录
```

## 阅读内核怎么做的

| 模块 | 说明 |
| --- | --- |
| `TextStyler` | 把章节正文构造成富文本。首行缩进用 `NSParagraphStyle` 实现而不是插空格，因此**字符偏移永远等于原文偏移**——换字号、换字体、简繁切换之后，书签和划线都不会错位 |
| `Paginator` | 基于 CoreText 的真分页：用 `CTFramesetterCreateFrame` + `CTFrameGetVisibleStringRange` 一页页量出字符范围。量的时候和画的时候用同一套参数，不会出现末行被裁掉半截 |
| `PageTextView` | 单页渲染视图，`CTFrameDraw` 直接绘制。同时负责划线绘制（背景/波浪线/直线三种样式）、听书跟读高亮、长按取词与拖拽选择 |
| `ReaderEngine` | 排版缓存 + 翻页导航 + 进度换算。按需排版并缓存前后各一章，翻页不掉帧；缓存超过 5 章自动回收 |
| `ReaderPagerController` | 五种翻页方式的统一容器（详见下表） |

### 五种翻页方式

| 方式 | 实现 |
| --- | --- |
| 覆盖（默认） | 自绘转场：新页跟手盖住旧页，带边缘阴影，可中途反悔 |
| 仿真 | `UIPageViewController` 的 pageCurl，页面不透明，卷曲背面不透光 |
| 平移 | 自绘转场：两页同步横移 |
| 无动画 | 直接切换，追求极速 |
| 上下滚动 | `UIScrollView` 承载整章连续排版，滚到底自动进入下一章 |

自绘转场统一走 `beginTransition → applyTransition(progress:) → finishTransition(commit:)` 三步，
所以「手指拖动」和「点击翻页」走的是同一条代码路径，手感一致；松手时按位移+速度判定是否翻过去，
翻页动画时长根据剩余距离动态计算（0.14s–0.36s），不会出现拖到 90% 松手还要等一个完整动画的情况。

## 相比番茄小说，具体做了哪些细节

**排版**
- 字号 13–30 逐级可调，行距 / 段距 / 页边距各 4 档，**字距**可以 -0.4 到 2.4 连续调（番茄没有字距）
- 五种中文字体（苹方 / 宋体 / 楷体 / 圆体 / 黑体），带候选字体名回退
- 首行缩进、两端对齐、正文加粗、简繁转换四个开关独立可控
- 页眉页脚元素（电量 / 时间 / 进度 / 本章页码）逐项可开关，不是一个总开关

**主题与光**
- 9 套配色（宣纸 / 净白 / 牛皮 / 护眼 / 天青 / 初樱 / 夜阑 / 暖夜 / 纯黑 OLED）
- 「宣纸」「牛皮」「暖夜」带极轻的 Canvas 纸纹，长时间看不至于太平
- 亮度可接管系统亮度，退出阅读自动还原
- **暖光滤镜**独立于亮度，用 multiply 混合叠在正文之上、菜单之下，比单纯调暗更护眼
- 跟随系统深色时自动切到指定的夜间主题，日间主题不被覆盖

**选中与批注**
- 长按取词用 `CFStringTokenizer` 做中文分词，选中的是「词」而不是一个字
- 拖动中实时扩展选区，松手后出现可拖拽的选区手柄（只在靠近手柄 34pt 内才拦截手势，不影响翻页）
- 划线支持 5 种颜色 × 3 种样式（背景 / 波浪线 / 直线），带想法的划线行尾有小圆点提示
- 重叠划线自动合并，不会越叠越脏
- 点击已有划线直接弹出操作条，可改色、写想法、删除
- 气泡菜单会根据选区在屏幕上下位置自动翻转，尽量不遮住正在读的句子

**听书**
- `AVSpeechSynthesizer` 朗读，语速 / 音色 / 定时关闭可调，中文音色按质量排序
- **正文跟读高亮**：朗读到哪句，哪句就有底色
- 朗读越过当前页会自动翻页；读完一章自动续下一章

**自动阅读**
- 两种模式：定时翻页 / 平滑滚动，速度由 `CADisplayLink` 逐帧驱动，不是 Timer 跳变
- 运行时底部有悬浮条，可直接加减速或退出，不用重新唤出菜单

**交互**
- 点击热区三种策略：左右翻页 / 全屏下一页 / 仅手势翻页
- 音量键翻页（用屏外 `MPVolumeView` 吃掉系统音量 HUD）
- 触感反馈分级：翻页是 soft、刻度是 selection、到头是 rigid
- 进度条自绘，34pt 命中高度，拖动时按 1/40 刻度给出细微震动，并实时显示将要跳到的章节名
- 到达首页/末页时页面有阻尼回弹 + 一次硬触感，而不是无声无息

**记录与关怀**
- 进度精确到字符偏移，不是「第几页」，换任何排版参数都能回到原句
- 护眼提醒（30/45/60 分钟可选）、每日阅读目标、连续阅读天数、最近七天时长柱状图
- 未加入书架的书退出时会询问是否加入书架
- 阅读时长每 30 秒落盘一次，退出时补记零头，杀进程也不会丢

## 已知边界

- 未接入书源，书城/搜索的数据全部来自 `SampleLibrary`；接真实书源时只需替换 `LibraryStore.books` 的来源，分页与阅读层无需改动
- 9 本陈列用样例书的正文由模板生成，章末已注明；3 本主推书籍为完整撰写内容
- 工程未在 Xcode 中实际编译过（开发环境无 macOS/Xcode 工具链），首次打开若有编译问题请以 Xcode 报错为准

## 网页版（可直接在手机上用）

`web/` 下是同一套阅读体验的 Web 实现，单文件、离线可用、无任何外部请求：

```bash
python3 web/build.py     # 从 ChengYue/Content/*.swift 抽取正文，生成 web/index.html
```

- 用 Safari 打开后「分享 → 添加到主屏幕」，即以全屏 App 形式运行（自带图标与 manifest）
- 分页用 CSS 多列实现真分页，页码/进度/划线坐标都基于 Range 量测，不是滚动模拟
- 长按取词用 `Intl.Segmenter` 做中文分词，选区手柄、划线三态、想法批注与原生版一致
- 五种翻页：覆盖 / 仿真（3D 翻卷）/ 平移 / 无动画 / 上下滚动，前三种跟手且可中途反悔
- 听书用 Web Speech API，`onboundary` 驱动跟读高亮与自动翻页
- 阅读进度、划线、书签、时长统计存在浏览器 localStorage 里
